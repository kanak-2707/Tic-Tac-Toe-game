# 🎮 Tic-Tac-Toe Game

A modern and responsive Tic-Tac-Toe game built using HTML, CSS and JavaScript.

## ✨ Features

- 👥 Two Player Mode
- 🤖 Play Against Computer
- 🏆 Winner Detection
- 📊 Score Tracking
- 💾 Score persistence using Local Storage
- 🌙 Dark Mode
- 📱 Responsive Design
- ✨ Smooth Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Storage API (Local Storage)

## 🚀 How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Start playing!
